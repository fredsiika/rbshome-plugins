# RBSHome plugins for Claude Code

Dallas and Collin County, Texas property, tax-delinquency and land records from your RBSHome account, inside Claude Code.

## Install (one command each)

```
/plugin marketplace add fredsiika/rbshome-plugins
/plugin install rbshome@rbshome
```

Then run `/mcp`, pick `rbshome`, and sign in with your RBSHome account (OAuth). A few tools work without signing in.

## What you get

- MCP server `rbshome` at `https://rbshome.com/api/mcp` (streamable HTTP).
- Skills: `buy-box-list`, `lead-due-diligence`, `upcoming-tax-sales`, `zip-market-screen`.

Sign up at https://rbshome.com. Questions: contact@rbshome.com.
